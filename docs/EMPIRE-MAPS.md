# Empire maps: prompts for ChatGPT

The American Empire has a painted Realm map (`kog-realm-map-kingdoms-v1.png`). The five new Empires show a simple drawn map until theirs are painted. When a painting is ready, I line it up with the Kingdom outlines (the same way as the American one), so tapping Realms and Kingdoms keeps working.

**For each Empire:** attach its reference map from **KOG Images → Map references** (`map-reference-GB.png` and so on) **in the same message**, so ChatGPT gets the shape of the country and the Realm borders right. Each Realm's color on the reference must stay the same color in the painting; that's how the app knows which Realm you tapped.

Save each painting in the KOG Images folder with the file name shown, then tell me.

## Setup message (send once)

Attach the American painting (`kog-realm-map-kingdoms-v1.png`) so ChatGPT matches its style, then send:

```
We're painting more Empire maps for King of the Greens, in exactly the same style as the attached American map: a vintage illustrated map with an ornate gold frame, a deep teal ocean with soft clouds, every Realm painted in its own bold color with a light texture, thin dark borders between the Kingdoms, and one detailed 3D miniature landmark per Realm standing on the map with a little putting green and flag. Landscape, 1672x941. No text, no labels, no real logos.

For each one I'll attach a reference map. Match its outline and Realm borders as closely as you can, and use EXACTLY the Realm colors shown on it (green #2fae7a, pink #e0528a, gold #e6b12e, orange #ec7a32, purple #8b7cf6, blue #3a9be0). Keep landmarks inside their own Realm and don't paint over the borders more than you need to. Reply "Ready".
```
